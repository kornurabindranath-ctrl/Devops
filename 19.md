# Self-Hosted GitHub Actions Runners on K8s Cost-efficient ephemeral runners using ARC scaling with workload demand.


create a eks cluster

bash
```
apiVersion: eksctl.io/v1alpha5
kind: ClusterConfig

metadata:
  name: github-runners-lab
  region: ap-south-1
  version: "1.34"

iam:
  withOIDC: true

managedNodeGroups:
  - name: workers
    instanceType: t3.medium
    desiredCapacity: 2
    minSize: 2
    maxSize: 4

    volumeSize: 30

    labels:
      role: github-runner

    ssh:
      allow: false
```

 create a namespace

 bash
 ```

install arc
bash
```
helm install arc \
  actions-runner-controller/actions-runner-controller \
  --namespace arc-systems \
  --set authSecret.create=false \
  --set authSecret.name=github-auth

# Deploy a Runner Scale Set

Now we'll deploy the actual runners that GitHub Actions jobs will use.

Get the Official Runner Scale Set Chart

bash
```
helm repo add gha-runner-scale-set https://actions.github.io/actions-runner-controller

helm repo update

helm search repo gha-runner-scale-set
```


Create runner-values.yaml

bash
```
githubConfigUrl: https://github.com/kornurabindranath-ctrl/Devops

githubConfigSecret: github-auth

runnerScaleSetName: github-runner-set

minRunners: 0
maxRunners: 5
```
